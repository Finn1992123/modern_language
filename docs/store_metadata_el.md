# Store Metadata Draft

## App Name

Modern Language

## Short Description

Η εφαρμογή μαθητών, γονέων και καθηγητών του Modern Language.

## Full Description

Το Modern Language app δίνει σε μαθητές, γονείς/κηδεμόνες και καθηγητές πρόσβαση στις βασικές λειτουργίες του φροντιστηρίου μέσα από μία εφαρμογή.

Οι χρήστες μπορούν να βλέπουν ανακοινώσεις, πρόγραμμα, εργασίες, βαθμούς, πρόοδο μαθημάτων, λεξιλόγιο, βιβλιοθήκη και ενημέρωση πληρωμών. Οι καθηγητές έχουν πρόσβαση σε εργαλεία τάξεων, μαθητών, εργασιών, απουσιών και προόδου.

Η εφαρμογή υποστηρίζει ασκήσεις λεξιλογίου με μελέτη, quiz, γραπτές απαντήσεις και προφορική εξάσκηση με μικρόφωνο/αναγνώριση ομιλίας.

## Privacy / Data Safety Notes

Η εφαρμογή συλλέγει ή επεξεργάζεται:

- email/login identifiers,
- στοιχεία προφίλ χρήστη,
- εκπαιδευτικά δεδομένα μαθητή,
- φωτογραφίες προφίλ όταν ο χρήστης τις επιλέγει,
- microphone/speech data κατά τη χρήση προφορικών ασκήσεων.

Η εφαρμογή δεν χρησιμοποιεί διαφημίσεις και δεν πουλά προσωπικά δεδομένα.

## Permissions Explanation

- Photos: επιλογή φωτογραφίας προφίλ.
- Microphone: προφορικές ασκήσεις λεξιλογίου.
- Speech recognition: έλεγχος προφορικής απάντησης.
- Internet: σύνδεση με Supabase backend.
