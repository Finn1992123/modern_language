# Έκδοση 1.0.5 (8)

Περιλαμβάνει τον τρέχοντα κώδικα της εφαρμογής και την εμφάνιση των παιδιών κάτω από τον γονιό στις πληρωμές καθηγητών.

Οι αλλαγές της βάσης εφαρμόζονται ξεχωριστά από το Android bundle:

- `supabase/migrations/202610050001_financial_debtor_children.sql`: επιστρέφει τα ονόματα των παιδιών στις πληρωμές. Χωρίς αυτήν, τα ονόματα δεν εμφανίζονται.
- `supabase/migrations/202609300001_live_dictation_any_translation_word.sql`: η ζωντανή ορθογραφία δέχεται απαντήσεις με οποιαδήποτε κοινή ολόκληρη λέξη της αποδεκτής μετάφρασης.

Η διαδικασία έκδοσης Android δεν επιβεβαιώνει ούτε αλλάζει την κατάσταση αυτών των migrations στη Supabase. Τα τοπικά αρχεία εισαγωγής οικογενειών και εξαγωγής μαθητών δεν αποτελούν μέρος του Android bundle.
